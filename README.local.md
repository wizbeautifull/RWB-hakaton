# Локальный запуск Wildberries Mesh

Один Docker Compose запускает сервер FastAPI и три веб-интерфейса. Покупатель, ПВЗ и продавец работают с одной локальной базой SQLite.

## 1. Подготовка

1. Скачай или клонируй репозиторий. Если скачиваешь ZIP с GitHub, распакуй его.
2. На Windows открой Docker Desktop и дождись статуса **Engine running**.
3. Открой PowerShell в папке проекта, где лежат `compose.yaml` и `Dockerfile`.

## 2. Запуск и загрузка демоданных

Выполни команды по очереди из корня проекта. Дождись статуса **Healthy** перед загрузкой данных.

```powershell
$env:MESH_PORT = '8000'
docker compose -p rwb-local up --build --wait
docker compose -p rwb-local exec app python -m backend.app.demo
```

Скрипт добавит три тестовых ПВЗ, три кабеля `CABLE` и два адаптера `ADAPTER` с длительным сроком хранения. Код продавца для отчёта — `seller-1`. Повторная загрузка сохраняет заказы и проведённые операции.

## 3. Открой три страницы

| Интерфейс | Адрес | Что проверить |
|---|---|---|
| Покупатель | [localhost:8000](http://localhost:8000/) | В каталоге есть кабель. Можно выбрать ПВЗ и оформить заказ. |
| Рабочее место ПВЗ | [localhost:8000/pvz/](http://localhost:8000/pvz/) | В рабочей точке ПВЗ А видны партии и остатки. |
| Кабинет продавца | [localhost:8000/seller/](http://localhost:8000/seller/) | Введи `seller-1` и нажми **«Показать отчёт»**. |

На страницах должен появиться статус **«API подключён»**. Дополнительно можно открыть [Swagger](http://localhost:8000/docs) и [проверку состояния API](http://localhost:8000/api/health). Последняя должна вернуть `{"status":"ok"}`.

Для быстрого прогона оформи один кабель в ПВЗ Б с WB Клубом и выбери **«Дождаться доставки в ПВЗ»**. На странице ПВЗ собери заказ в А и передай курьеру. Затем переключись на Б, прими и выдай посылку. Подтверждай операции кодом из карточки покупателя. На чистых демоданных после выдачи в А останутся два доступных кабеля.

## Если порт занят

В первой строке запуска укажи `8001` вместо `8000`, затем выполни команды запуска и загрузки данных в том же PowerShell. Открой те же адреса с портом `8001`. Если одновременно поднимаешь второй стенд из той же папки, укажи для него другое имя проекта после `-p` во всех командах. Это даст второму стенду отдельный том базы.

Если контейнер запустился с ошибкой или страницы показывают **«Демо-режим»**, проверь состояние и журнал приложения.

```powershell
docker compose -p rwb-local ps
docker compose -p rwb-local logs --tail 100 app
```

## Остановка и повторный запуск

```powershell
docker compose -p rwb-local down
```

База SQLite хранится в томе `orders`. При следующем запуске с тем же именем `rwb-local` стенд подключит прежнюю базу. Для новой чистой репетиции выбери другое имя Compose-проекта и загрузи демоданные для него.

## Яндекс Карты

В версии с картами базовый сценарий работает с выбором точки из списка. Для режима с JavaScript API Яндекс Карт укажи браузерный ключ в переменной `MESH_YANDEX_MAPS_KEY` до запуска Compose. При настройке ключа используй разрешённый адрес `localhost` для локального запуска.
